# graphic-tests

A simple CLI runner for graphical tests.

The project is still at a very early stage of development. At the moment, the argument parser is ready, but the actual test execution logic is still minimal.

## Running

From the workspace root:

```bash
cargo run -p graphic-tests -- [OPTIONS]
```

From the `graphic-tests` directory:

```bash
cargo run -- [OPTIONS]
```

## Available options

### `--test-name`, `-t`

Runs a single test by name.

Default value:

```text
All
```

Example:

```bash
cargo run -p graphic-tests -- --test-name Triangle
```

### `--graphic-api`, `-g`

Limits execution to a specific graphics API.

Available values:

```text
all
wgpu
```

Default value:

```text
all
```

Examples:

```bash
cargo run -p graphic-tests -- --graphic-api wgpu
cargo run -p graphic-tests -- --test-name Triangle --graphic-api wgpu
```

## CLI help

To see the help generated by `clap`:

```bash
cargo run -p graphic-tests -- --help
```

## Current status

Right now the program only parses arguments and runs a stub test runner. The actual test dispatching and image comparison logic is still in progress.
